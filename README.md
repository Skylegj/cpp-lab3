
# Лабораторная работа №3: Циклы с ветвлениями

## Автор

Чеботников А.В. (Вариант 30)

## Цель

Изучение циклов for и условных операторов if, else if, else в C++ на примере расчёта параметров течения воды в трубе.

## Описание

Программа рассчитывает параметры течения воды по гладкой трубе при различных скоростях.

Вычисляются:
- Число Рейнольдса Re.
- Коэффициент трения λ.
- Потеря давления Δp.
- Мощность P, необходимая для преодоления потери давления.

Для выбора формулы коэффициента трения используются условные операторы. Расчёты выполняются с помощью цикла for.

## Исходные данные

Для проверки программы используются следующие значения:

- Длина трубы l: 4 м
- Диаметр трубы d: 0.01 м
- Плотность воды ρ: 998 кг/м³
- Кинематическая вязкость ν: 0.000001 м²/с

Скорости воды: 0.02; 0.05; 0.1; 0.2; 0.4; 0.6; 1.0 м/с.

Параметры трубы и воды вводятся с клавиатуры. Скорости хранятся в массиве и обрабатываются циклом for.

## Ожидаемые результаты

Программа выводит таблицу значений скорости, числа Рейнольдса, коэффициента трения, потери давления и мощности.

Примеры результатов:

- При w = 0.02 м/с: Re = 200, λ = 0.32, Δp = 25.5488 Па, P ≈ 0.000040132 Вт.
- При w = 1 м/с: Re = 10000, λ = 0.03164, Δp = 6315.344 Па, P ≈ 0.496006 Вт.

## Запуск программы
